# CMB DXF Viewer + Excel

회사 내부 사용을 전제로 한 Windows DXF 읽기 전용 Viewer + Excel 추출 프로그램입니다.

## 고정 보안/라이선스 정책
- 입력은 DXF만 지원
- DWG 읽기/변환 기능 없음
- ODA, LibreDWG 등 DWG 엔진 미포함
- 원본 DXF 수정/저장 기능 없음
- 서버 업로드 없음
- AI 호출 없음
- 인터넷 연결 불필요
- 모든 작업은 로컬 PC에서 수행

## Viewer 기능
- DXF 열기
- 마우스 휠 확대/축소
- 우클릭/중클릭 드래그 PAN
- 전체보기
- 레이어 개별 ON/OFF / 전체 보기 / 전체 숨김
- 객체 클릭 선택
- Shift + 클릭 다중 객체 선택/해제
- ESC 선택 해제
- 선택 객체 유형 / 레이어 / Handle / 블록 / 문자 정보 확인
- 현재 마우스 CAD X/Y 좌표 표시
- 좌표 확인 모드
- 두 점 거리 측정
- 다각형 면적/둘레 측정
- LINE, LWPOLYLINE, POLYLINE, CIRCLE, ARC, POINT, TEXT, MTEXT, INSERT,
  SPLINE, ELLIPSE, SOLID, TRACE, 3DFACE, 일부 HATCH/RAY/XLINE 표시
- INSERT 블록은 virtual entities를 이용해 읽기 전용으로 화면 전개

## v2.2 기반 레이어 선택
- 처음 DXF를 열면 모든 레이어가 체크되어 Viewer에 표시됨
- 체크된 레이어 = Viewer에 표시되는 레이어 = Excel 추출 대상
- 체크 해제 즉시 Viewer에서 해당 레이어가 사라지고 Excel 추출 대상에서도 제외됨
- 다시 체크하면 Viewer에 다시 표시되고 Excel 추출 대상에도 포함됨
- 일반 행 클릭: 해당 행을 파란색 선택
- 다른 행 일반 클릭: 기존 선택 해제 후 새 행을 파란색 선택
- Shift + 행 클릭: 기준점부터 해당 행까지 연속 파란 범위 선택
- 파란 범위 안 체크박스 클릭:
  클릭 항목이 미체크면 범위 전체 체크,
  체크 상태면 범위 전체 체크 해제
- 체크 변경 후 파란 범위 유지

## 시험용 단순 설치 버전 (2026-10-07)
- 설치 패키지 버전: 3.20.1 (Viewer 실행 파일: 기존 v3.20-clean)
- 로그인, 설치 계정, 서버 승인, 고지 동의 창 및 서버 완료 기록 절차 제거

- 제어판에서 제거 가능. 기존 사용자 DXF/Excel 파일은 보존
- build-installer.ps1에 CompilerPath, AppExe, LicenseFile, OutputFile을 지정해 빌드

## v3.24 필요한 광주간선·주관로만 추출
1. 광주간선 추출 → 시작 함체/광케이블 끝점 → 끝 함체/끝점 클릭
2. 두 점 사이의 유일한 연결 경로와 해당 함체만 화면 표시. STUB 및 경로 밖 가지 제외
3. 보이는 항목 Excel 추출 → 광주간선/함체 요약 및 선택 경로의 굴곡 좌표만 출력
4. 여러 연결 경로가 있으면 임의 선택하지 않으며 더 짧은 구간 선택 안내
5. 100mm 주관로 추출: 명시 관경 또는 사용자가 로컬에서 확인한 100mm만 표시·추출. 50mm 및 미확인은 제외
6. PL0/P0만으로 관경을 추정하지 않음. 관경 확인 창에서 선택 관로 위치를 보고 확인한 지름 지정 가능(현재 세션에만 적용)
7. 기본 Excel 출력은 추출 대상 선택이 필요. 기존 전체 출력은 파일 > 전체 레이어 Excel (기존 방식)
8. 전체 도면 보기로 추출 필터 해제. 광 끝점 선택 중 ESC로 취소

## v3.25 추출 모드 배경 지형도
- 선택한 광경로/관로 위에 건물·지번·도로 등 배경 레이어를 함께 표시
- 처음 범위 선택 시 선택 경로에 맞춰 확대하고 주변 지형도를 같은 좌표로 표시
- 표시 범위와 Excel 대상 범위를 분리. 배경은 출력하지 않음
- 최신 요청에 따라 기본 광 추출물은 광케이블 요약/경로좌표만 출력. 함체는 화면에서 위치 참고용으로 유지
- 관로 출력은 확인된 100mm 관로와 그 경로좌표만 유지
