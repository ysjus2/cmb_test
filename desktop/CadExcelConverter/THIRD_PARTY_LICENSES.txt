Scope
=====
This notice applies to the v3.20-clean Windows build of CMB_DXF_Viewer.exe.
The application is intended for company-internal editing/use. External users
access the separate server/mobile service and do not receive this EXE.

Verified clean-build result
===========================
The frozen EXE was inspected after PyInstaller packaging. The v3.20-clean
build contains no NumPy, fontTools, OpenBLAS, or libscipy_openblas archive
entries. The NumPy -> OpenBLAS/LAPACK -> GCC Runtime Library chain present in
v3.19 is therefore not present in this build.

No ODA File Converter, ODA SDK, LibreDWG, dwgread.exe, or dwg2dxf.exe is
bundled. The application is DXF-only.
